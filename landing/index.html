    Have it run without you

    A workflow can start on a cron schedule, when a file changes, or from a local webhook. These three controls work, so go ahead.

    08:30
    30 8 * * 1-5

    Pick at least one day. This schedule would never run.

    curl -X POST http://127.0.0.1:8787/hooks/<triggerId> \
      -H "Authorization: Bearer <token>" \
      -d '{"branch":"main"}'
    Waiting for a request

    The real listener binds to 127.0.0.1 only and rejects a missing or wrong token.

    Questions you may have

    Is Alfred really free?

    Yes. Official builds and source builds are free, and nobody is ever required to pay. In official builds, schedules and triggers unlock with an optional one time supporter licence. A build you compile yourself has them on from the start. Manual runs are free in every build.

    Do I need another AI subscription?

    No. Alfred launches the CLIs you have already signed in to. Whatever Claude, Cursor, OpenAI or another provider charges for its own service stays between you and that provider.

    Which agents does it work with?

    Claude Code, Cursor, Codex, OpenCode, GitHub Copilot, Gemini CLI and Grok Build. A custom agent step can also run your own agent command.

    Does my code leave my machine?

    Local workflows stay on your machine unless you choose to publish a template through the optional sharing service. A running step still sends its prompt and data to the CLI or connected service you configured for it.

    Does Alfred store my API keys?

    Not for your agents. The Provider CLI harness shells out to CLIs already authenticated on your machine, so their credentials stay with them.

    Which platforms are supported?

    macOS 11 or later, Windows 10 and 11, and Linux. macOS builds are Developer ID signed, notarized and stapled. The Windows installer is an unsigned beta, so Windows reports an unknown publisher and SmartScreen may warn you.

    What happens when Alfred is closed?

    Schedules, file triggers and webhooks only run while the app is open, including in the tray or menu bar. For a scheduled time missed while Alfred was closed, each schedule follows its own choice: catch up on open, skip the run, or ask you.

    Can I build it from source?

    Yes. The build guide covers it. You need Bun, Rust and the platform prerequisites for Tauri, and the result has every feature enabled.

    How do updates work?

    From version 1.2.0 on, Alfred checks at launch and from the Help menu, asks before installing, then restarts. Your workflows, runs, schedules and memories are local and survive an upgrade.

    Alfred is dressed and ready

    Free and open source. No account and no card. You can delete it whenever you like, and your agents will carry on as before.
